# Team Roles

## Four-person suggestion
- Product/integration lead: owns scope, decisions, integration, submission.
- Backend/data lead: API, data validation, model orchestration.
- Frontend/demo lead: user journey, UI, deployment.
- Evaluation/story lead: metrics, test cases, documentation, pitch.

Everyone contributes code where practical. Establish endpoint contracts and mock data in first hour. Sync every 60–90 minutes; demo from `main` every two hours. See [[Integration Checklist]].
