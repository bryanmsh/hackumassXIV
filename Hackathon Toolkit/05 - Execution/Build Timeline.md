# Build Timeline

## 10-hour engineering schedule (example, not official agenda)
| Time ET | Goal | Gate |
|---|---|---|
| 10–11 | Choose problem, metric, scope | One-page spec approved |
| 11–13 | Scaffold frontend, backend, sample data | One end-to-end request works |
| 13–16 | Core feature | Measurable output works |
| 16–17:30 | Integration, tests | Clean demo run |
| 17:30–18:30 | Deploy and backup video | Public URL / local fallback |
| 18:30–20 | README, submission | Confirmed before cutoff |

**Hard rule:** if not integrated by 16:00, drop stretch features. Reserve last 30+ minutes for submission, not coding.
