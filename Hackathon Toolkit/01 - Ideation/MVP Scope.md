# MVP Scope

## Project
- User:
- One-sentence problem:
- Input:
- Output:
- AI-specific value:
- Dataset/API:
- Success metric and baseline:

## Must work
- [ ] One frontend screen
- [ ] One API endpoint
- [ ] One real or representative data flow
- [ ] One defensible result

## Stretch only
- [ ] Authentication
- [ ] Analytics
- [ ] Multi-user collaboration

## Kill criteria
If core integration fails by midpoint, switch to a smaller end-to-end demo. Never fake results or imply simulated data are real.
