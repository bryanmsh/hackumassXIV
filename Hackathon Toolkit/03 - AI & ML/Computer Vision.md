# Computer Vision

## Fast prototype options
- Pretrained image classifier for fixed categories.
- Object detection for locating multiple objects.
- OCR for text in images (verify manually).
- Simulator/synthetic image data for robotics track.

## Evaluate
Record dataset provenance, 10+ representative images, failure cases, precision/recall or classification accuracy, latency. Don't claim physical robot performance from simulation. Docs: https://huggingface.co/tasks
