# Judging Criteria

## What is verified
Hackachusetts official submission guidance says judging took place Saturday evening and directed participants to campus hosts for judging criteria/scoring rubric. It does **not** publish a verified numeric weighting in the public page.

## Our internal practice rubric (not official)
- Problem/impact 25%
- Working demo 25%
- Technical execution 20%
- Evidence/evaluation 15%
- Novelty 10%
- Communication 5%

Use this only for team rehearsal; adjust when an event publishes actual criteria.
