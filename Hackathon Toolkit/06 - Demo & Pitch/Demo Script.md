# Demo Script

## 90-second template
**0–15s Problem:** Who struggles, and what concrete decision is hard?
**15–30s Product:** Show the user and input.
**30–65s Live workflow:** Run one real end-to-end example; explain AI's precise role.
**65–80s Evidence:** State baseline, observed result, dataset size, limitations.
**80–90s Close:** Why it matters; next iteration.
