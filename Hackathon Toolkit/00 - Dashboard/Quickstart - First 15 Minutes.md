# Quickstart - First 15 Minutes

1. Open [[Hackathon Home]].
2. Read [[Hackachusetts 2026 Research]] (historical) or replace with the current event's rules.
3. Score 3 candidate projects using [[Idea Scoring Matrix]].
4. Fill [[MVP Scope]] and [[Architecture Template]].
5. Assign [[Team Roles]] and make first end-to-end request using [[FastAPI]] and [[React + TypeScript]].
6. Create repo and submit a test commit with [[Git & GitHub]].
