# Submission Checklist

- [ ] Confirm current competition's exact deadline and time zone
- [ ] Confirm eligibility, team size, track and AI/tool rules
- [ ] Repository URL opens to judges; remove secrets
- [ ] README includes problem, demo, setup, architecture and sources
- [ ] Working demo link or video tested on a second device
- [ ] Project submission form completed and confirmation saved
- [ ] Screenshots and backup video stored locally
- [ ] Attributions and data licenses documented
- [ ] Team member names and roles accurate
- [ ] Final submission completed at least 30 minutes before deadline
