# Event Rules

## Hackachusetts 2026 (historical; recheck for future events)
- Massachusetts enrolled students, .edu registration, student ID checked.
- Solo or up to four members.
- Four challenge tracks; project deadline 8 PM ET on October 24.
- Kiro was the featured/powered-by AI development environment; read original rules before asserting exact tool-use requirements for another event.
- Confirm submission method, repository access, video/demo requirements and team membership against the live event page; a GitHub push is not necessarily a complete submission.
- Judging rubric: ask host; official public page does not publish numeric criteria.

Sources: https://massaicoalition.com/hackachusetts/submitting-projects/ and https://massaicoalition.com/hackachusetts/
