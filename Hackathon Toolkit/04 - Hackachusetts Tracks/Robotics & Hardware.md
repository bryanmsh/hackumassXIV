# Robotics & Hardware

Official illustrative themes: manufacturer automation, robo-gym, data quality, swarm rescue, messy desk sorting, infrastructure inspection, path planning. Source: https://hackachusetts2026.vercel.app/

## Candidate MVP: messy-desk vision sorter
Input: labeled sample desk images. Output: detected object classes and a simulated pick order. Metric: class precision/recall, route length or processing time. Tech: [[Computer Vision]], simple planner, web simulator.

## Alternative
Inspection triage for open images; prioritize review, do not claim autonomous safety clearance.
